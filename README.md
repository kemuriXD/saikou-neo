An anime-focused TV app with native interfaces and shared Kotlin Multiplatform
logic. Android TV and Android-based Fire TV come first, with an Android phone
companion for account sign-in and TV pairing.

## Project status

**Early Alpha — no public release yet.**

- **Foundation complete:** shared core, native TV/companion shells and local build checks.
- **Working in local test builds:** sample playback/resume, AniList/MAL sign-in and QR/code TV pairing.
- **Next:** provider Library and tracking, real catalogue data, extensions and the native TV design.
- **Later:** iPhone companion and Apple TV, sharing core logic with native UIs.

The public repository currently contains the workflow scaffold. The app
implementation remains local; full source and downloadable builds are not
published yet. Local test results do not imply release readiness.

## Follow development

Explore the **[roadmap](https://github.com/users/kemuriXD/projects/1)** for planned
features, current work and release checks. Browse **[existing issues](https://github.com/kemuriXD/saikou-neo/issues)**

Playback source support is planned through separately installed extensions;
no playback sources will be bundled with the app.
