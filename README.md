# SaikouTV2

A fresh, TV-first rebuild of SaikouTV, developed in small, verified stages.

**Current stage: repository foundation and scope decisions.** This repository
does not contain an Android application yet. Its automated checks currently
validate documentation; they do not demonstrate that an app builds or works.

## Direction

- Android TV is the first implementation target.
- Android-based Fire TV compatibility will be verified on physical hardware.
- The owner's Fire TV model and operating system are still to be confirmed.
- Apple TV research and Vega OS implementation are deferred.
- The previous [SaikouTV repository](https://github.com/kemuriXD/SaikouTV) is
  reference material. Any reused code must have recorded provenance and review.
- Each stage needs acceptance criteria, test evidence, and resolved blocking
  defects before the next stage starts.
